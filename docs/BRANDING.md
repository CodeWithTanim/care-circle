# Hackathon logo banner

`hackathon-logos.svg` presents the four original logos supplied in `public/`:

- `hack2skills.png`
- `MnM.png`
- `catalyst.png`
- `google-developers.png`

The SVG embeds the original PNG bytes without changing their colors, proportions, or transparency. Each logo has a contrasting panel so the white wordmarks remain visible on both light and dark README backgrounds. Text below the logos provides a readable organization name.

The banner is self-contained and uses no external image requests. These logos acknowledge the hackathon organizations; they do not imply product endorsement. The original files remain unchanged.
